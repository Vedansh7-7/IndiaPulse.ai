Provenance. Every figure on this page is computed from the public Olist Brazilian E-Commerce dataset (~99k orders, ~41k free-text reviews). There are no hand-tuned effect constants in the engine. Retrieved web context is labelled as context and is excluded from evidence scoring by design.

Method is region-agnostic: it requires a KPI time series plus timestamped unstructured text, and applies wherever both exist.
